# 运行zocde是否需要启用GPU


## **用户** 2026-09-25 10:21

跑zocde 我需要把gpu拉起来不？


## **助手** 2026-09-25 10:21

**不需要，GPU 保持省电模式就行。**

ZCode 跑起来是「网络请求 + 读写本地文件 + 文本处理」，全吃 CPU、内存、网络，完全用不到 GPU。拉起 GPU 只会白费电、白发热，反而更烫。

真正该关心的是截图里另外两个数：

- **CPU 100% / 95°C** —— 已经在过热降频的边缘了，这才是 ZCode 变卡的来源
- **RAM 12.6 / 15.6 GB** —— 快满了，本地跑编译、索引时会卡

所以：模式维持「增强」即可（别开「手动」去解锁 GPU），想提速就关掉几个吃 CPU 的后台程序，而不是动 GPU。

唯一的例外：如果你要在本地跑模型（Ollama / LM Studio 之类），那才需要 GPU 上工——纯用 ZCode 连 API 的话用不上。

## **助手** 2026-09-25 10:22

风扇没不干活——截图里 **CPU 风扇 5200 RPM、GPU 风扇 4800 RPM**，都已经在转，而且转速不低了（增强模式基本就是拉高风扇曲线的模式）。

GPU 省电模式影响的只是独显本身（不给它供电），不会管风扇。**现在 95°C 是 CPU 一个人烤出来的，把 GPU 打开只会多一个热源，温度更高，不是更凉。**

所以结论不变：GPU 不用开。真想压这 95°C，有效的是：

- 关掉占 CPU 100% 的那个进程（任务管理器看看是谁在满载）
- 机身进风口/散热口清灰、垫高笔记本增加进风
- 风扇已经 5000+ 转还压不住的话，就是硅脂/积灰的问题了，软件层面到头了
